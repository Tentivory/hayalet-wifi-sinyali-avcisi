# 👻 HAYALET WİFİ SİNYALİ AVCISI v1.0

## Evrenin En İleri Düzey, Bilimsel Olarak Kanıtlanmış, Tamamen Gereksiz Ama Muhteşem Hayalet Ağ Tarayıcısı

Bu proje, modern bilimin ulaştığı en yüksek noktayı temsil etmektedir. 
Görünmez WiFi sinyallerini, paralel evrenlerden sızan ağları ve hayalet router'ları tespit etmek için özel olarak tasarlanmıştır.

### Neden Bu Yazılım?

Çünkü normal WiFi tarayıcıları sadece **görünür** sinyalleri gösterir. 
Biz ise **görünmeyeni** gösteriyoruz. 
Evet, hiçbir şey göstermiyoruz aslında ama bunu çok ciddi bir şekilde yapıyoruz.

### Özellikler

- 🔍 Gerçek zamanlı hayalet sinyal taraması
- 📡 Sinyal gücü ölçümü (1%% ile 42%% arasında, çünkü 42 cevap)
- 👻 Rastgele hayalet ağ isimleri üretimi
- 🧠 Felsefi düzeyde bağlantı reddi mesajları
- ⚡ Süper hızlı tarama (gerçek hayatta 3.5 saniye sürer)
- 🛡️ Hiçbir güvenlik açığı yok çünkü hiçbir şey yapmıyor

### Kurulum

```bash
git clone https://github.com/Tentivory/hayalet-wifi-sinyali-avcisi.git
cd hayalet-wifi-sinyali-avcisi
python3 hayalet_avcisi.py
```

### Kullanım

Programı çalıştırın. 
Tarama yapın. 
Hayaletleri görün (veya görmeyin).
